# Use of AI

This project is developed with the help of an AI assistant. This document records what it was used for, so it is clear which work is the author's and which was AI-assisted.

**Tool:** [Claude Code](https://claude.com/claude-code) (Anthropic), model Claude Opus 5.5, used in VS Code.

## How AI is used

- **The author decides.** Requirements, scope and design choices are made by the author. The AI proposes, explains trade-offs and points out problems; the author accepts, corrects or rejects them.
- **Everything is reviewed.** AI output (text, configuration, code) is read, run and tested by the author before it is committed.
- **Commits stay the author's.** The author commits and pushes; the AI does not push to the repository.
- **Scaffolding tools are not AI.** Files generated by standard tools (`sv create` for SvelteKit, `cargo`, `wasm-pack`, Paraglide) are produced by those tools, even when the AI ran the command.
