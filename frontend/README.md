# Frontend

SvelteKit app with the visitor PWA and the admin interface. TypeScript, Tailwind CSS, Paraglide (all UI text goes through `messages/en.json`), Vitest, ESLint and Prettier. Built with `adapter-static` as a single-page app that the Axum server serves.

Normally run through Docker Compose from the repository root (see [docs/development.md](../docs/development.md)). Without Docker:

```sh
npm install
npm run dev      # http://localhost:5173, proxies /api to http://localhost:8080
npm run check    # svelte-check / TypeScript
npm run lint     # Prettier + ESLint
npm test         # Vitest
npm run build    # static build in build/
```

`src/lib/wasm/` is generated by the `wasm` service (wasm-pack) and is not committed.
